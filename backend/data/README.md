# Fund universe

`fund_universe.csv` lists the funds FolioWise considers. NAV history, metrics
and scores are all computed from it. It is generated by
`scripts/fetch_funds.py`; do not edit it by hand.

## Selection rule

Every **open-ended, direct-plan, growth-option** fund in our six categories
that is still active (a NAV in the last 30 days) and has at least **5 years of
NAV history**.

Nothing is hand-picked. Picking well-known or large funds would build bias into
the list, because funds usually become well known through past returns; ranking
them on past returns would then partly measure why they were picked. Here every
eligible fund is included and ranked against its whole category.

Known limitation: funds that closed or merged are not in AMFI's current list,
so a category's history still carries some survivorship bias.

## Sources

- **AMFI's daily NAV file** (amfiindia.com/spages/NAVAll.txt): every active
  scheme with its official SEBI category. Categories come from here, not from
  fund names.
- **mfapi.in**: each scheme's full NAV history.

## How to refresh

From the `backend` folder:

```bash
python scripts/fetch_funds.py            # reuses NAV files already downloaded
python scripts/fetch_funds.py --refresh  # downloads every NAV file again
```

Check `rejected.csv` afterwards: it lists every candidate that failed a check
and why.

## Categories

| `category` | AMFI category headings accepted | Extra name rule |
|---|---|---|
| `large_cap_index` | Other Scheme - Index Funds; Index Funds - Equity Funds | name contains "Nifty 50" or "Nifty Index Fund" (not Next 50, Equal Weight, etc.) |
| `flexi_cap` | Equity Scheme(s) - Flexi Cap Fund | |
| `mid_cap` | Equity Scheme(s) - Mid Cap Fund | |
| `small_cap` | Equity Scheme(s) - Small Cap Fund | |
| `debt` | Debt Scheme - Corporate Bond Fund; Income/Debt Oriented Schemes - Corporate Bond Fund | |
| `gold` | Other Scheme - FoF Domestic; Fund of Funds Scheme (Domestic) | name contains "Gold" (not silver or multi-asset) |

AMFI's file uses more than one heading for some categories, and both
"Scheme" and "Schemes"; the script accepts all of them. Plan and option come
from the file's own Plan and Option columns.
